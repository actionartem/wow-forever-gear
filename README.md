# WoW Forever — экипировка Орды

Статический справочник экипировки 60-го уровня для подготовки к первым рейдам. Все девять классов, 28 подборок с отдельными наборами кота и медведя.

Карточки содержат характеристики, иконки, источники добычи, инструкции квестов и крафта, ссылки на предметы и рецепты. Данные новых подборок проверены 13 ноября 2026. Исходный набор кота датирован 12 ноября 2026.

## Данные

Основные списки — WOWTBC.GG Forever. Они не ранжированы. Номер билда каталога не указан. Точные ID и иконки сопоставлены с Forever Cache из Napalmsteak/WoW-Classic-Item-Caches. Дополнительные источники и ограничения указаны рядом с конкретными инструкциями. Неизвестные места получения новых рецептов отмечены явно.

Подборки в `feral.json`, `bear.json`, `healers.json`, `melee.json`, `casters.json`, `hunter.json`. Общие маршруты подземелий в `dungeons.json`. Каждый предмет хранит собственные ссылки и происхождение данных.

## Изображения

Для всех 28 специализаций используются отдельные официальные изображения Blizzard из серии Legion Class Preview. Это иллюстрации специализаций; игровые данные остаются данными Forever. Оригиналы, ссылки на статьи и авторство сохранены в `art.json`; файлы лежат в `art/` и загружаются с самого сайта. При смене спека изображение обновляется без перезагрузки страницы.

## Локальный просмотр

Сборка и серверная часть не требуются. Для локального просмотра из корня репозитория запустить `python -m http.server 8765` и открыть `http://localhost:8765`. GitHub Pages публикует корень ветки `main`.
